## 🧩 Exercícios Implementados

A aplicação possui 4 telas (componentes) diferentes:

1. **Sobre Mim (/sobre)**
   - **Foco:** Roteamento com @page.
   - **Descrição:** Página simples exibindo título e texto informacional sobre mim.

2. **Contador de Clicks (/contador)**
   - **Foco:** Eventos e Lógica (@code e @onclick).
   - **Descrição:** Um botão que incrementa uma variável, mostrando a atualização da tela em tempo real.

3. **Alternador de Mensagem (/mensagem)**
   - **Foco:** Estado Booleano e Interatividade.
   - **Descrição:** Botão que alterna a exibição de uma mensagem na tela usando a estrutura condicional @if.

4. **Placar Interativo (/placar)**
   - **Foco:** Desafio Integrador.
   - **Descrição:** Placar de jogo com opções para somar, subtrair (com limite zerado) e reiniciar os pontos.

## 🛠️ Tecnologias Utilizadas
- **C#** e **.NET**
- **Blazor** (Componentes .razor, HTML + C#)
